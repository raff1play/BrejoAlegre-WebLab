# ADR-0001 — Protótipo web descartável

**Status:** ACEITA pelo usuário (11/11/2026)

**Contexto:** custo de desenvolvimento, desejo de validar direção, visual e logística sem implementar antes multiplayer/servidor Android.

**Decisão:** criar Web Lab com Babylon.js, TypeScript e Vite, single-player, sem backend, para validação rápida. O futuro jogo Godot será reconstruído do zero se o conceito for aprovado.

**Consequências:** código de câmera/física web provavelmente será descartado; conhecimento, especificações, art assets com licença e dados verificáveis poderão ser reutilizados. Não substituir decisão original D13 para o produto final.
